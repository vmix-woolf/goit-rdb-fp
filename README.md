# Фінальний проєкт — Аналіз пандемічних даних (MySQL)

## Крок 1. Завантаження та попередній аналіз даних
- Створено схему **`pandemic`** у базі даних.
- Імпортовано CSV-файл з даними про інфекційні захворювання за допомогою **Table Data Import Wizard** у таблицю `infectious_cases`.
- Проведено первинний аналіз структури даних.
- Виявлено дублювання атрибутів `Entity` та `Code`, що надалі потребувало нормалізації.
- Типи даних скориговано: числові показники (`cases`, `number_...`) збережено як `INT` або `FLOAT`,  
  а текстові (`country`, `country_code`) — як `VARCHAR`.

---

## Крок 2. Нормалізація даних до 3НФ
- Створено окрему таблицю **`countries`** для унікальних назв країн та їх кодів.
- Додано **первинний ключ** `id` у таблицю `countries`.
- У таблицю `infectious_cases` додано поле `country_id` і створено **зовнішній ключ** `fk_country`,  
  який забезпечує зв’язок між таблицями.
- Видалено колонки `country` та `country_code` з таблиці `infectious_cases`.
- Таблицю `infectious_cases` приведено до 3-ї нормальної форми.
- Деякі колонки перейменовано у формат **snake_case** для зручності роботи  
  (наприклад, `Entity → country`, `Code → country_code`, `Number_rabies → number_rabies`,  
  `Number_cholera_cases → cholera_cases`), зберігаючи початковий зміст назв.

---

## Крок 3. Аналітичний запит
- Для кожної унікальної країни обчислено:
    - середнє (`AVG`),
    - мінімальне (`MIN`),
    - максимальне (`MAX`)
    - та сумарне (`SUM`) значення показника **`number_rabies`**.
- Враховано порожні значення (`NULL`) — вони були відфільтровані.
- Результат відсортовано за середнім значенням у спадному порядку.
- Виведено лише **10 рядків** з найвищими середніми значеннями.

---

## Крок 4. Побудова колонки різниці в роках
- Для колонки `year` побудовано:
    - нову колонку **`year_start_date`** — дата 1 січня відповідного року (`MAKEDATE(year, 1)`),
    - колонку **`current_date_value`** — поточна дата (`CURDATE()`),
    - колонку **`years_diff`** — різниця в роках між цими двома датами (`TIMESTAMPDIFF(YEAR, ...)`).
- Перевірено коректність обчислень: наприклад, для 1920 - 1929 років.
